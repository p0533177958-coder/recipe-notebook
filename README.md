# 📖 מחברת מתכונים

אפליקציית מתכונים אישית בעברית לטלפון אנדרואיד. היא מותקנת למסך הבית ועובדת גם בלי אינטרנט.
כל מתכון מחולק לשלבים, ובמצב בישול רואים שלב אחד גדול בכל מסך, עם המצרכים של אותו שלב וטיימרים שמופעלים מתוכו.
מוסיפים מתכון בשיתוף מאפליקציה אחרת, בהדבקת טקסט או בצילום, ו-Gemini הופך אותו למתכון מסודר.
אין שרת ואין התחברות: כל הנתונים נשמרים במכשיר.

## הרצה מקומית

צריך [Node.js](https://nodejs.org) גרסה 20 ומעלה.

```bash
npm install
```

```bash
npm run dev
```

האפליקציה תיפתח בכתובת `http://localhost:5173`.
ה-Service Worker לא פעיל במצב פיתוח. כדי לבדוק התקנה ועבודה אופליין, בונים ומריצים את הגרסה הסופית:

```bash
npm run build
```

```bash
npm run preview
```

וגולשים ל-`http://localhost:4173`.

| פקודה | מה היא עושה |
|---|---|
| `npm run dev` | שרת פיתוח |
| `npm run build` | בדיקת טיפוסים ובנייה לתיקיית `dist` |
| `npm test` | בדיקות Vitest |
| `npm run icons` | יצירה מחדש של האייקונים מ-`scripts/icon.svg` |

## מפתח Gemini חינמי

בלי מפתח אפשר להשתמש בכל האפליקציה (כולל שלושת המתכונים לדוגמה), חוץ מהפיכת טקסט או תמונה למתכון.

1. נכנסים ל-[Google AI Studio](https://aistudio.google.com/apikey) עם חשבון גוגל.
2. לוחצים **Create API key** ומעתיקים את המפתח.
3. באפליקציה: ⚙️ הגדרות ← מדביקים בשדה "מפתח Gemini API" ← **בדוק מפתח**.

המפתח נשמר רק במכשיר. בשכבה החינמית יש מכסה יומית, וגוגל רשאית להשתמש בתוכן שנשלח לשיפור המודלים.
שם המודל מוגדר בקובץ אחד, `src/config.ts` (ברירת מחדל: `gemini-2.5-flash`).

## העלאה לאוויר בחינם

התקנה למסך הבית ו-Share Target עובדים **רק בכתובת HTTPS**. כל אחת מהאפשרויות הבאות נותנת HTTPS בחינם.

### GitHub Pages (מוכן מראש)

בפרויקט כבר יש קובץ `.github/workflows/deploy.yml` שבונה ומעלה אוטומטית בכל push.

1. יוצרים ריפו חדש ב-GitHub (למשל `recipe-notebook`).
2. מעלים אליו את הפרויקט:

```bash
git remote add origin https://github.com/USERNAME/recipe-notebook.git
```

```bash
git push -u origin main
```

3. בריפו: **Settings ← Pages ← Source: GitHub Actions**.
4. אחרי כדקה האפליקציה זמינה בכתובת `https://USERNAME.github.io/recipe-notebook/`.

ה-workflow מגדיר את `BASE_PATH` לפי שם הריפו, ולכן כל הנתיבים יוצאים נכונים.

### Netlify או Cloudflare Pages

מחברים את הריפו, או גוררים את תיקיית `dist` אחרי `npm run build`:

- פקודת בנייה: `npm run build`
- תיקיית פלט: `dist`

הקובץ `public/_redirects` כבר מטפל בניתוב של אפליקציית עמוד-יחיד. אין צורך ב-`BASE_PATH`, כי האתר יושב בשורש הדומיין.

## התקנה על אנדרואיד

1. פותחים את כתובת האפליקציה ב-**Chrome**.
2. תפריט ⋮ ← **התקנת אפליקציה** (או "הוספה למסך הבית").
3. האייקון מופיע במסך הבית והאפליקציה נפתחת במסך מלא.

אחרי ההתקנה "מחברת מתכונים" מופיעה ברשימת השיתוף של אנדרואיד: בוואטסאפ, בכרום, בגלריה או בפתקים לוחצים "שיתוף" ובוחרים בה.

## מה יש באפליקציה

- **הוספת מתכון:** שיתוף מאפליקציה אחרת (טקסט, תמונות או קובץ `.recipe.json`), הדבקת טקסט, צילום, או בחירה מהגלריה. כמה תמונות מסודרות בגרירה ונשלחות יחד כמתכון אחד.
- **עיבוד ב-AI:** מצרכים בדיוק כמו במקור, פירוק לשלבים קצרים, שיוך מצרכים לשלבים, טיימרים אוטומטיים, קטגוריה, תגיות ואימוג'י. אחרי העיבוד מגיע מסך עריכה מלא, ו"הצג מקור" מראה את התמונות והטקסט המקוריים.
- **טיוטות:** אם האפליקציה נסגרת באמצע, ממשיכים בדיוק מאותה נקודה.
- **מסך הבית:** חיפוש לפי שם, תגית או מצרך (עמיד לניקוד, לה' הידיעה ולכתיב מלא/חסר), קטגוריות, "הכנתי לאחרונה", תצוגת רשת או שורות (נשמרת), מיון, ולחיצה ארוכה לתפריט פעולות.
- **מצב בישול:** שלב אחד גדול בכל מסך, מצרכי השלב, החלקה, הגדלה והקטנה של הטקסט, והמסך נשאר דלוק.
- **טיימרים:** כמה במקביל, עמידים לרענון ולמעבר לאפליקציה אחרת, צלצול נעים ורטט עד שלוחצים "עצור", הקראה בעברית והתראת מערכת.
- **שליטה קולית:** "הבא", "הקודם", "הפעל טיימר", "עצור", "כמה זמן נשאר", "תקריא", "מצרכים".
- **שיתוף:** טקסט מעוצב לוואטסאפ, או קובץ שאפשר לייבא אצל מישהו אחר.
- **גיבוי:** ייצוא כל המתכונים והתמונות לקובץ אחד, וייבוא שממזג בלי כפילויות.

## מבנה הקוד

```
src/
  strings.he.ts     כל הטקסטים בממשק
  config.ts         שם המודל, גדלי תמונות
  types.ts          מבנה הנתונים
  db.ts             Dexie (IndexedDB)
  seed.ts           המתכונים לדוגמה
  sw.ts             Service Worker: אופליין, Share Target, לחיצה על התראה
  lib/              לוגיקה: חיפוש, טיימרים, AI, תמונות, גיבוי, קול, צליל
  hooks/            טיימרים, Wake Lock, זיהוי דיבור, לחיצה ארוכה
  components/       רכיבי ממשק משותפים
  pages/            המסכים
tests/              בדיקות Vitest
```

החלטות שהמפרט השאיר פתוחות מתועדות ב-[DECISIONS.md](DECISIONS.md).

## בדיקה ידנית בטלפון

רוב הדברים נבדקו בדפדפן, אבל את אלה אפשר לבדוק רק במכשיר אמיתי:

- **Share Target:** שיתוף מוואטסאפ, מהגלריה (כמה תמונות) ומכרום, אחרי התקנה.
- **שליטה קולית:** זיהוי הדיבור בעברית ב-Chrome לאנדרואיד, והפעלה מחדש אוטומטית אחרי שקט.
- **Wake Lock:** המסך לא נכבה במצב בישול, וחוזר לפעול אחרי מעבר לאפליקציה אחרת.
- **צלצול, רטט והתראה:** כשהאפליקציה ברקע. כרום מאט דפים ברקע, ולכן ההתראה עלולה להתעכב מעט; כשחוזרים לאפליקציה הטיימר מצלצל מיד.
- **צילום:** פתיחת המצלמה מכפתור "צלם".
